Rust 程序设计语言

简介

注意：本书的这一版与 No Starch Press 出版的纸质版和电子书版《Rust 程序设计语言》内容相同。

欢迎阅读《Rust 程序设计语言》，这是一本关于 Rust 的入门书。Rust 程序设计语言能帮助你编写更快、更可靠的软件。在编程语言设计中，高层次的易用性和底层的控制能力往往难以兼得；Rust 则向这一矛盾发起了挑战。通过在强大的技术能力与出色的开发体验之间取得平衡，Rust 让你可以控制底层细节（比如内存使用），而不必承受传统上与这种控制相伴的种种麻烦。

Rust 适合哪些人

出于各种各样的原因，Rust 适合很多人。我们来看看其中最重要的几类人群。

开发团队

事实证明，对于由系统编程知识水平参差不齐的开发者组成的大型团队来说，Rust 是一款高效的协作工具。底层代码容易出现各种隐蔽的 bug，在大多数其他语言中，这些 bug 只能依靠大量的测试以及经验丰富的开发者细致的代码审查才能发现。而在 Rust 中，编译器扮演着守门人的角色，它会拒绝编译含有这些难以捉摸的 bug 的代码，其中也包括并发 bug。与编译器协同工作，团队就可以把时间花在程序逻辑上，而不是疲于追查 bug。

Rust 还为系统编程世界带来了现代化的开发工具：

  • Cargo 是 Rust 自带的依赖管理器和构建工具，它让添加、编译和管理依赖变得轻松省事，并且在整个 Rust 生态系统中保持一致。
  • rustfmt 格式化工具确保不同开发者之间的代码风格保持一致。
  • Rust Language Server 为集成开发环境（IDE）提供支持，实现代码补全和行内错误提示等功能。

借助这些工具以及 Rust 生态系统中的其他工具，开发者在编写系统级代码时也能保持高效。

学生

Rust 适合学生以及有志于学习系统相关概念的人。许多人通过 Rust 学习了操作系统开发等主题。Rust 社区非常热情友好，乐于解答学生的问题。Rust 团队希望通过本书这样的努力，让更多人——尤其是编程新手——更容易接触到系统相关的概念。

公司

成百上千家大大小小的公司在生产环境中使用 Rust 完成各种各样的任务，包括命令行工具、Web 服务、DevOps 工具、嵌入式设备、音视频分析与转码、加密货币、生物信息学、搜索引擎、物联网应用、机器学习，甚至 Firefox 网页浏览器的主要组成部分。

开源开发者

Rust 适合那些想要参与构建 Rust 程序设计语言本身、社区、开发者工具和库的人。我们非常欢迎你为 Rust 语言做出贡献。

重视速度和稳定性的人

Rust 适合那些渴望语言兼具速度与稳定性的人。这里所说的速度，既指 Rust 代码运行得有多快，也指 Rust 能让你多快地写出程序。Rust 编译器的检查能确保你在添加功能和重构代码时程序依然稳定。这与那些缺少此类检查的语言中脆弱的遗留代码形成了鲜明对比——开发者往往不敢去修改那样的代码。Rust 致力于实现零成本抽象——让高层次的特性编译成与手写代码一样快的底层代码——力求让安全的代码同时也是快速的代码。

Rust 语言还希望能为许多其他用户提供支持；这里提到的只是其中一些最主要的利益相关者。总的来说，Rust 最大的抱负是消除程序员们几十年来一直被迫接受的取舍：同时提供安全性和生产力、速度和易用性。不妨试试 Rust，看看它的这些选择是否适合你。

本书面向的读者

本书假定你已经用其他某种编程语言写过代码，但并不限定是哪一种。我们尽量让本书的内容适合各种编程背景的读者。我们不会花大量篇幅讨论编程是什么，或者该如何思考编程。如果你完全是编程新手，那么最好先读一本专门介绍编程入门的书。

如何阅读本书

总体来说，本书假定你是从头到尾按顺序阅读的。后面的章节建立在前面章节的概念之上，前面的章节可能不会深入探讨某个主题的细节，而是会在后面的章节中再回过头来讨论。

本书包含两类章节：概念章节和项目章节。在概念章节中，你将学习 Rust 的某个方面；在项目章节中，我们会一起构建小程序，运用你到目前为止所学的知识。第 2 章、第 12 章和第 21 章是项目章节，其余都是概念章节。

第 1 章介绍如何安装 Rust、如何编写一个“Hello, world!”程序，以及如何使用 Rust 的包管理器和构建工具 Cargo。第 2 章通过让你构建一个猜数字游戏，手把手地带你入门 Rust 编程。这一章只会从较高的层面介绍各种概念，后面的章节会提供更多细节。如果你想马上动手实践，第 2 章正适合你。如果你是一位特别细致的学习者，喜欢先弄清每个细节再继续往下学，那么你可以跳过第 2 章，直接阅读第 3 章，这一章介绍了 Rust 中与其他编程语言相似的特性；之后，当你想通过做项目来运用学到的细节时，再回到第 2 章。

在第 4 章中，你将学习 Rust 的所有权系统。第 5 章讨论结构体和方法。第 6 章介绍枚举、match 表达式，以及 if let 和 let...else 控制流结构。你将使用结构体和枚举来创建自定义类型。

在第 7 章中，你将学习 Rust 的模块系统，以及用于组织代码及其公有应用程序编程接口（API）的私有性规则。第 8 章讨论标准库提供的一些常见集合数据结构：vector、字符串和哈希 map。第 9 章探讨 Rust 的错误处理理念和技巧。

第 10 章深入讲解泛型、trait 和生命周期，它们让你能够定义适用于多种类型的代码。第 11 章全部是关于测试的内容，即使有 Rust 的安全保证，测试对于确保程序逻辑正确仍然必不可少。在第 12 章中，我们将自己实现 grep 命令行工具的一部分功能，用来在文件中搜索文本。为此，我们会用到前面几章讨论过的许多概念。

第 13 章探讨闭包和迭代器：它们是 Rust 中源自函数式编程语言的特性。在第 14 章中，我们将更深入地研究 Cargo，并讨论与他人分享库的最佳实践。第 15 章讨论标准库提供的智能指针，以及赋予它们这些功能的 trait。

在第 16 章中，我们将逐一介绍并发编程的不同模型，并讨论 Rust 如何帮助你无所畏惧地进行多线程编程。在第 17 章中，我们会在此基础上探索 Rust 的 async 和 await 语法，以及任务、future 和流，还有它们所带来的轻量级并发模型。

第 18 章考察 Rust 的惯用法与你可能熟悉的面向对象编程原则之间有何异同。第 19 章是关于模式和模式匹配的参考，它们是在 Rust 程序中表达想法的强大方式。第 20 章是一份高级主题大杂烩，内容包括 unsafe Rust、宏，以及关于生命周期、trait、类型、函数和闭包的更多知识。

在第 21 章中，我们将完成一个项目：实现一个底层的多线程 Web 服务器！

最后，还有一些附录以更接近参考手册的形式提供了关于这门语言的实用信息。附录 A 介绍 Rust 的关键字，附录 B 介绍 Rust 的运算符和符号，附录 C 介绍标准库提供的可派生 trait，附录 D 介绍一些实用的开发工具，附录 E 讲解 Rust 的版次。在附录 F 中，你可以找到本书的各种翻译版本；在附录 G 中，我们将介绍 Rust 是如何开发的，以及什么是 nightly Rust。

阅读本书没有错误的方式：如果你想跳着读，尽管去做！如果遇到困惑，你可能需要回到前面的章节。总之，怎么适合你就怎么来。

学习 Rust 的一个重要环节，是学会阅读编译器显示的错误信息：它们会引导你写出能够正常工作的代码。因此，我们会提供许多无法编译的示例，并附上编译器在每种情况下显示的错误信息。请注意，如果你随便输入并运行一个示例，它可能无法编译！一定要阅读示例周围的文字，看看你要运行的示例是不是本来就会出错。在大多数情况下，我们都会引导你得到无法编译的代码的正确版本。Ferris 也会帮助你辨别那些本来就无法正常工作的代码：

Ferris含义
这段代码无法编译！
这段代码会 panic！
这段代码不能产生预期的行为。

在大多数情况下，我们都会引导你得到无法编译的代码的正确版本。
