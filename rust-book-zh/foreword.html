Rust 程序设计语言

前言

短短几年间，Rust 程序设计语言已经走过了很长的路：从最初由一个规模不大、刚刚起步的爱好者社区创造和孵化，到如今成为全世界最受喜爱、需求最旺盛的编程语言之一。回头来看，Rust 的强大能力与广阔前景必然会引人注目，并在系统编程领域站稳脚跟。而并非必然的是，人们对它的兴趣和围绕它的创新在全球范围内不断增长，渗透到各个开源社区，并推动它在各行各业得到大规模采用。

时至今日，要解释人们为何对 Rust 兴趣激增、纷纷采用，很容易就能举出 Rust 所提供的种种出色特性。谁不想要内存安全，还要高性能，还要友好的编译器，还要出色的工具，外加许多其他美妙的特性呢？你今天看到的 Rust 语言，融合了多年来系统编程领域的研究成果，以及一个充满活力与热情的社区所积累的实践智慧。这门语言经过了目标明确的设计和精心的打磨，为开发者提供了一件工具，让编写安全、快速、可靠的代码变得更加容易。

但真正让 Rust 与众不同的，是它的初心：赋予你——也就是使用者——实现目标的能力。这是一门希望你取得成功的语言，而“赋能”这一理念贯穿于构建、维护和推广这门语言的社区的核心。自本权威著作的上一版问世以来，Rust 已经进一步成长为一门真正全球化、值得信赖的语言。如今，Rust 项目得到了 Rust 基金会的有力支持，基金会还投资于一些关键举措，以确保 Rust 安全、稳定且可持续地发展。

这一版《Rust 程序设计语言》是一次全面的更新，反映了这门语言多年来的演进，并提供了许多有价值的新内容。但它不仅仅是一本讲解语法和库的指南——它还是一份邀请，邀请你加入一个重视质量、性能和深思熟虑的设计的社区。无论你是第一次探索 Rust 的资深开发者，还是希望精进技艺的老练 Rustacean，这一版都能为你带来收获。

Rust 的历程是一段协作、学习和不断迭代的旅程。这门语言及其生态系统的成长，直接体现了它背后那个充满活力、多元的社区。从核心语言设计者到偶尔参与的贡献者，成千上万名开发者的贡献，正是 Rust 成为如此独特而强大的工具的原因。拿起这本书，你不仅仅是在学习一门新的编程语言——你还加入了一场运动，一同让软件变得更好、更安全、用起来更愉快。
