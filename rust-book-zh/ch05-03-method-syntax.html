Rust 程序设计语言

方法

方法与函数类似：它们都使用 fn 关键字和名字来声明，都可以有参数和返回值，并且都包含一些在被其他地方调用时运行的代码。与函数不同的是，方法是在结构体（或者枚举、trait 对象，我们会分别在第 6 章和第 18 章介绍它们）的上下文中定义的，并且它们的第一个参数总是 self，代表调用该方法的结构体实例。

方法语法

我们把以 Rectangle 实例作为参数的 area 函数改写成定义在 Rectangle 结构体上的 area 方法，如示例 5-13 所示。

为了在 Rectangle 的上下文中定义函数，我们为 Rectangle 开启一个 impl（implementation，实现）块。这个 impl 块中的所有内容都将与 Rectangle 类型相关联。然后，我们把 area 函数移到 impl 的大括号中，并将签名中的第一个（在这里也是唯一的）参数以及函数体中所有用到它的地方都改为 self。在 main 中，原先我们调用 area 函数并将 rect1 作为实参传入，现在则可以改用方法语法（method syntax）在 Rectangle 实例上调用 area 方法。方法语法写在实例之后：加上一个点号，后面跟着方法名、圆括号以及所需的实参。

在 area 的签名中，我们使用 &self 代替了 rectangle: &Rectangle。&self 实际上是 self: &Self 的简写。在 impl 块中，Self 类型是该 impl 块所对应类型的别名。方法的第一个参数必须是一个名为 self、类型为 Self 的参数，所以 Rust 允许你在第一个参数的位置只写 self 这个名字作为简写。注意，我们仍然需要在 self 简写前面加上 &，以表明这个方法借用了 Self 实例，就像在 rectangle: &Rectangle 中那样。和其他任何参数一样，方法可以获取 self 的所有权，可以像这里这样不可变地借用 self，也可以可变地借用 self。

我们在这里选择 &self 的理由，与在函数版本中使用 &Rectangle 的理由相同：我们不想获取所有权，只想读取结构体中的数据，而不是写入数据。如果想要在方法中修改调用该方法的实例，就需要使用 &mut self 作为第一个参数。只用 self 作为第一个参数来获取实例所有权的方法很少见；这种技巧通常用于方法将 self 转换成其他东西，并且你希望防止调用者在转换之后继续使用原来的实例的情况。

使用方法而不是函数，除了可以使用方法语法、不必在每个方法的签名中重复 self 的类型之外，主要原因在于代码组织。我们把对一个类型的实例能做的所有事情都放在了一个 impl 块中，而不是让将来使用我们代码的人在我们提供的库中到处寻找 Rectangle 的功能。

通常（但并非总是如此），当我们给方法起一个与字段相同的名字时，我们希望它只返回字段中的值，而不做其他任何事情。这类方法被称为 getter，Rust 并不像其他一些语言那样自动为结构体字段实现 getter。getter 很有用，因为你可以把字段设为私有，而把方法设为公有，从而将对该字段的只读访问作为该类型公有 API 的一部分。我们会在第 7 章讨论什么是公有和私有，以及如何将字段或方法指定为公有或私有。

-> 运算符到哪去了？

在 C 和 C++ 中，调用方法时会用到两种不同的运算符：如果直接在对象上调用方法，就使用 .；如果在指向对象的指针上调用方法，需要先对指针解引用，就使用 ->。换句话说，如果 object 是一个指针，那么 object->something() 就类似于 (*object).something()。

Rust 并没有与 -> 等效的运算符；相反，Rust 有一个叫作自动引用和解引用（automatic referencing and dereferencing）的功能。方法调用是 Rust 中少数几个具有这种行为的地方之一。

它的工作原理是这样的：当你使用 object.something() 调用方法时，Rust 会自动为 object 添加 &、&mut 或 *，以便使 object 与方法签名相匹配。也就是说，下面这两种写法是等价的：

#![allow(unused)]
fn main() {
#[derive(Debug,Copy,Clone)]
struct Point {
    x: f64,
    y: f64,
}

impl Point {
   fn distance(&self, other: &Point) -> f64 {
       let x_squared = f64::powi(other.x - self.x, 2);
       let y_squared = f64::powi(other.y - self.y, 2);

       f64::sqrt(x_squared + y_squared)
   }
}
let p1 = Point { x: 0.0, y: 0.0 };
let p2 = Point { x: 5.0, y: 6.5 };
p1.distance(&p2);
(&p1).distance(&p2);
}

第一种写法看起来要简洁得多。这种自动引用的行为之所以可行，是因为方法有一个明确的接收者（receiver），也就是 self 的类型。在给定接收者和方法名的情况下，Rust 可以明确地判断出该方法是在读取（&self）、修改（&mut self）还是消耗（self）数据。Rust 对方法接收者的借用是隐式的，这在很大程度上让所有权在实践中用起来更加顺手。

关联函数

所有在 impl 块中定义的函数都被称为关联函数（associated function），因为它们与 impl 后面所命名的类型相关联。我们可以定义第一个参数不是 self 的关联函数（因此它们不是方法），因为它们并不需要类型的实例就能工作。我们已经用过一个这样的函数了：定义在 String 类型上的 String::from 函数。

不是方法的关联函数经常被用作构造函数，返回该结构体的一个新实例。它们通常被命名为 new，但 new 并不是一个特殊的名字，也没有内置于语言之中。例如，我们可以提供一个名为 square 的关联函数，它只有一个表示边长的参数，并将其同时用作宽度和高度，这样创建正方形的 Rectangle 时就更容易了，不必把同一个值指定两次：

文件名：src/main.rs

#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn square(size: u32) -> Self {
        Self {
            width: size,
            height: size,
        }
    }
}

fn main() {
    let sq = Rectangle::square(3);
}

返回类型和函数体中的 Self 关键字都是 impl 关键字后面所出现类型的别名，在这里就是 Rectangle。

要调用这个关联函数，我们在结构体名后使用 :: 语法，例如 let sq = Rectangle::square(3);。这个函数位于结构体的命名空间中：:: 语法既用于关联函数，也用于模块创建的命名空间。我们会在第 7 章讨论模块。

总结

结构体让你可以创建出在你的领域中有意义的自定义类型。通过使用结构体，你可以将相关联的数据片段联系在一起，并为每个片段命名，让代码更加清晰。在 impl 块中，你可以定义与你的类型相关联的函数，而方法是一种关联函数，它让你可以指定结构体实例所具有的行为。

但结构体并不是创建自定义类型的唯一方式：接下来我们来学习 Rust 的枚举功能，为你的工具箱再添一件工具。
