Rust 程序设计语言

控制流

根据条件是否为 true 来决定是否运行某段代码，以及在条件为 true 时重复运行某段代码，是大多数编程语言中的基本组成部分。在 Rust 中，用来控制代码执行流程的最常见结构是 if 表达式和循环。

if 表达式

if 表达式让你可以根据条件让代码产生分支。你提供一个条件，然后表示：“如果满足这个条件，就运行这段代码；如果不满足，就不运行这段代码。”

在你的 projects 目录下新建一个名为 branches 的项目来探索 if 表达式。在 src/main.rs 文件中输入以下内容：

文件名：src/main.rs

fn main() {
    let number = 3;

    if number < 5 {
        println!("condition was true");
    } else {
        println!("condition was false");
    }
}

所有的 if 表达式都以关键字 if 开头，后面跟一个条件。在这个例子中，条件检查变量 number 的值是否小于 5。我们把条件为 true 时要执行的代码块放在条件之后，用花括号括起来。与 if 表达式中的条件相关联的代码块有时也叫作分支（arm），就像我们在第 2 章“比较猜测的数字和秘密数字”部分讨论过的 match 表达式中的分支一样。

我们还可以选择性地加上一个 else 表达式（这里我们就这样做了），为程序提供一个在条件求值为 false 时执行的备选代码块。如果你没有提供 else 表达式而条件为 false，程序就会直接跳过 if 代码块，继续执行后面的代码。

试着运行这段代码，你应该会看到如下输出：

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
condition was true

我们试着把 number 的值改成一个使条件为 false 的值，看看会发生什么：

fn main() {
    let number = 7;

    if number < 5 {
        println!("condition was true");
    } else {
        println!("condition was false");
    }
}

再次运行程序，然后查看输出：

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
condition was false

另外值得注意的是，这段代码中的条件必须是 bool 类型。如果条件不是 bool，就会得到一个错误。例如，试着运行下面的代码：

文件名：src/main.rs

fn main() {
    let number = 3;

    if number {
        println!("number was three");
    }
}

这次 if 条件的求值结果是 3，于是 Rust 抛出了一个错误：

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
error[E0308]: mismatched types
 --> src/main.rs:4:8
  |
4 |     if number {
  |        ^^^^^^ expected `bool`, found integer

For more information about this error, try `rustc --explain E0308`.
error: could not compile `branches` (bin "branches") due to 1 previous error

这个错误表明 Rust 期望得到一个 bool，却得到了一个整数。与 Ruby 和 JavaScript 等语言不同，Rust 不会自动尝试把非布尔类型转换为布尔类型。你必须显式地为 if 提供一个布尔值作为条件。例如，如果我们希望 if 代码块只在某个数字不等于 0 时运行，可以把 if 表达式改成下面这样：

文件名：src/main.rs

fn main() {
    let number = 3;

    if number != 0 {
        println!("number was something other than zero");
    }
}

运行这段代码会打印出 number was something other than zero。

使用 else if 处理多个条件

你可以把 if 和 else 组合成 else if 表达式来使用多个条件。例如：

文件名：src/main.rs

fn main() {
    let number = 6;

    if number % 4 == 0 {
        println!("number is divisible by 4");
    } else if number % 3 == 0 {
        println!("number is divisible by 3");
    } else if number % 2 == 0 {
        println!("number is divisible by 2");
    } else {
        println!("number is not divisible by 4, 3, or 2");
    }
}

这个程序有四条可能的执行路径。运行它之后，你应该会看到如下输出：

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
number is divisible by 3

这个程序执行时，会依次检查每个 if 表达式，并执行第一个条件求值为 true 的代码块。注意，尽管 6 可以被 2 整除，我们却没有看到输出 number is divisible by 2，也没有看到 else 代码块中的 number is not divisible by 4, 3, or 2 文本。这是因为 Rust 只会执行第一个条件为 true 的代码块，而且一旦找到一个，就不会再检查剩下的条件了。

使用过多的 else if 表达式会让代码变得杂乱，所以如果你有不止一个 else if，可能就需要重构代码了。第 6 章会介绍一种适用于这些情况的强大的 Rust 分支结构，叫作 match。

在 let 语句中使用 if

因为 if 是一个表达式，所以我们可以把它放在 let 语句的右侧，把结果赋值给一个变量，如示例 3-2 所示。

变量 number 将会绑定到一个基于 if 表达式结果的值上。运行这段代码，看看会发生什么：

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.30s
     Running `target/debug/branches`
The value of number is: 5

请记住，代码块的值是其中最后一个表达式的值，而数字本身也是一个表达式。在这个例子中，整个 if 表达式的值取决于执行的是哪个代码块。这意味着 if 的每个分支可能返回的值都必须是相同的类型；在示例 3-2 中，if 分支和 else 分支的结果都是 i32 整数。如果类型不匹配，就像下面这个例子一样，我们会得到一个错误：

文件名：src/main.rs

fn main() {
    let condition = true;

    let number = if condition { 5 } else { "six" };

    println!("The value of number is: {number}");
}

当我们尝试编译这段代码时，会得到一个错误。if 分支和 else 分支的值类型互不兼容，Rust 会准确地指出程序中问题所在的位置：

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
error[E0308]: `if` and `else` have incompatible types
 --> src/main.rs:4:44
  |
4 |     let number = if condition { 5 } else { "six" };
  |                                 -          ^^^^^ expected integer, found `&str`
  |                                 |
  |                                 expected because of this

For more information about this error, try `rustc --explain E0308`.
error: could not compile `branches` (bin "branches") due to 1 previous error

if 代码块中的表达式求值为一个整数，而 else 代码块中的表达式求值为一个字符串。这样是行不通的，因为变量必须只有一种类型，而且 Rust 需要在编译时就确切地知道 number 变量是什么类型。知道了 number 的类型，编译器就能在每一处使用 number 的地方验证其类型是否有效。如果 number 的类型只能在运行时确定，Rust 就无法做到这一点；如果编译器必须为每个变量跟踪多种假设的类型，它就会变得更加复杂，对代码能做出的保证也会更少。

使用循环重复执行

多次执行同一段代码常常很有用。为此，Rust 提供了几种循环（loop），循环会把循环体中的代码执行到末尾，然后立即回到开头重新开始。为了试验循环，我们来新建一个名为 loops 的项目。

Rust 有三种循环：loop、while 和 for。我们逐一来试试。

使用 loop 重复执行代码

loop 关键字告诉 Rust 一遍又一遍地执行一段代码，要么永远执行下去，要么直到你明确地让它停下来为止。

举个例子，把 loops 目录中的 src/main.rs 文件修改成这样：

文件名：src/main.rs

fn main() {
    loop {
        println!("again!");
    }
}

运行这个程序时，我们会看到 again! 被不停地反复打印，直到我们手动停止程序为止。大多数终端都支持用键盘快捷键 ctrl-C 来中断陷入无限循环的程序。来试一试：

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/loops`
again!
again!
again!
again!
^Cagain!

符号 ^C 表示你按下 ctrl-C 的位置。

在 ^C 之后，你可能会也可能不会看到 again! 这个单词被打印出来，这取决于代码收到中断信号时正执行到循环中的哪个位置。

幸运的是，Rust 也提供了一种用代码跳出循环的方法。你可以在循环中放置 break 关键字，告诉程序何时停止执行循环。回想一下，我们在第 2 章“猜对后退出”部分的猜数字游戏中就是这样做的：当用户猜中数字赢得游戏时退出程序。

我们在猜数字游戏中还用到了 continue，在循环中它会告诉程序跳过本次迭代中剩余的代码，直接进入下一次迭代。

从循环中返回值

loop 的用途之一是重试一个你知道可能会失败的操作，例如检查某个线程是否已经完成了它的工作。你可能还需要把这个操作的结果从循环中传递给代码的其余部分。为此，你可以在用于停止循环的 break 表达式之后加上想要返回的值；这个值会从循环中返回，供你使用，如下所示：

fn main() {
    let mut counter = 0;

    let result = loop {
        counter += 1;

        if counter == 10 {
            break counter * 2;
        }
    };

    println!("The result is {result}");
}

在循环之前，我们声明了一个名为 counter 的变量，并将其初始化为 0。接着，我们声明了一个名为 result 的变量，用来保存循环返回的值。在循环的每次迭代中，我们都给 counter 变量加 1，然后检查 counter 是否等于 10。如果相等，就使用 break 关键字并带上值 counter * 2。在循环之后，我们用一个分号结束把值赋给 result 的语句。最后，我们打印出 result 中的值，在这个例子中是 20。

你也可以在循环内部使用 return。break 只会退出当前循环，而 return 总是会退出当前函数。

用循环标签消除歧义

如果循环中还嵌套着循环，break 和 continue 作用于此处最内层的循环。你可以选择在某个循环上指定一个循环标签（loop label），然后将其与 break 或 continue 一起使用，表明这些关键字作用于带标签的那个循环，而不是最内层的循环。循环标签必须以一个单引号开头。下面是一个包含两层嵌套循环的例子：

fn main() {
    let mut count = 0;
    'counting_up: loop {
        println!("count = {count}");
        let mut remaining = 10;

        loop {
            println!("remaining = {remaining}");
            if remaining == 9 {
                break;
            }
            if count == 2 {
                break 'counting_up;
            }
            remaining -= 1;
        }

        count += 1;
    }
    println!("End count = {count}");
}

外层循环带有标签 'counting_up，它会从 0 数到 2。没有标签的内层循环则从 10 倒数到 9。第一个没有指定标签的 break 只会退出内层循环，而 break 'counting_up; 语句会退出外层循环。这段代码会打印：

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.58s
     Running `target/debug/loops`
count = 0
remaining = 10
remaining = 9
count = 1
remaining = 10
remaining = 9
count = 2
remaining = 10
End count = 2

用 while 简化条件循环

程序经常需要在循环中对某个条件求值。当条件为 true 时，循环继续运行；当条件不再为 true 时，程序调用 break 停止循环。这样的行为可以组合使用 loop、if、else 和 break 来实现；如果你愿意，现在就可以在程序中试一试。不过，这种模式太常见了，所以 Rust 为它内置了一种语言结构，叫作 while 循环。在示例 3-3 中，我们使用 while 让程序循环三次，每次倒数一个数，然后在循环结束后打印一条消息并退出。

这种结构消除了使用 loop、if、else 和 break 时所需的大量嵌套，而且更加清晰。只要条件求值为 true，代码就会运行；否则就退出循环。

使用 for 遍历集合

你可以选择使用 while 结构来遍历集合（例如数组）中的元素。例如，示例 3-4 中的循环会打印出数组 a 中的每个元素。

这里，代码会逐个递增地遍历数组中的元素。它从索引 0 开始，一直循环到数组的最后一个索引（也就是 index < 5 不再为 true 时）。运行这段代码会打印出数组中的每个元素：

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.32s
     Running `target/debug/loops`
the value is: 10
the value is: 20
the value is: 30
the value is: 40
the value is: 50

正如预期的那样，数组中的五个值都出现在了终端中。尽管 index 在某个时刻会达到 5，但循环会在尝试从数组中获取第六个值之前停止执行。

然而，这种做法很容易出错；如果索引值或测试条件不正确，就可能导致程序 panic。例如，如果你把数组 a 的定义改为包含四个元素，却忘了把条件更新为 while index < 4，代码就会 panic。这种做法也很慢，因为编译器会添加运行时代码，在每次循环迭代时都进行条件检查，判断索引是否在数组的边界之内。

作为一种更简洁的替代方案，你可以使用 for 循环，对集合中的每一项执行一些代码。for 循环的写法如示例 3-5 中的代码所示。

运行这段代码时，我们会看到与示例 3-4 相同的输出。更重要的是，我们现在提高了代码的安全性，消除了因越过数组末尾或者没有遍历到末尾而漏掉某些元素所导致 bug 的可能。由 for 循环生成的机器码也可能更加高效，因为不需要在每次迭代时都把索引与数组长度进行比较。

使用 for 循环时，如果你改变了数组中值的数量，并不需要像使用示例 3-4 中的方法那样记着去修改其他代码。

for 循环的安全性和简洁性使它成为 Rust 中最常用的循环结构。即使在你想要将某段代码运行特定次数的情况下，例如示例 3-3 中使用 while 循环的倒计时例子，大多数 Rustacean 也会使用 for 循环。具体做法是使用标准库提供的 Range，它会按顺序生成从一个数字开始、到另一个数字之前结束的所有数字。

下面是使用 for 循环以及另一个我们还没有讲过的方法 rev（用来反转范围）来实现倒计时的写法：

文件名：src/main.rs

fn main() {
    for number in (1..4).rev() {
        println!("{number}!");
    }
    println!("LIFTOFF!!!");
}
