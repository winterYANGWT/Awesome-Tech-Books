Rust 程序设计语言

数据类型

Rust 中的每个值都属于某种数据类型（data type），数据类型告诉 Rust 所指定的是哪类数据，从而让它知道如何处理这些数据。我们将看到两类数据类型子集：标量（scalar）和复合（compound）。

请记住，Rust 是一门静态类型（statically typed）语言，这意味着它必须在编译时就知道所有变量的类型。编译器通常可以根据值以及我们使用它的方式推断出我们想用的类型。当可能存在多种类型时，例如在第 2 章“比较猜测的数字和秘密数字”部分中使用 parse 将 String 转换为数字类型时，我们就必须添加类型注解，像这样：

#![allow(unused)]
fn main() {
let guess: u32 = "42".parse().expect("Not a number!");
}

如果不添加上面代码中的 : u32 类型注解，Rust 就会显示如下错误，意思是编译器需要我们提供更多信息，才能知道我们想用哪种类型：

$ cargo build
   Compiling no_type_annotations v0.1.0 (file:///projects/no_type_annotations)
error[E0284]: type annotations needed
 --> src/main.rs:2:9
  |
2 |     let guess = "42".parse().expect("Not a number!");
  |         ^^^^^        ----- type must be known at this point
  |
  = note: cannot satisfy `<_ as FromStr>::Err == _`
help: consider giving `guess` an explicit type
  |
2 |     let guess: /* Type */ = "42".parse().expect("Not a number!");
  |              ++++++++++++

For more information about this error, try `rustc --explain E0284`.
error: could not compile `no_type_annotations` (bin "no_type_annotations") due to 1 previous error

对于其他数据类型，你会看到不同的类型注解。

标量类型

标量（scalar）类型表示单个值。Rust 有四种基本的标量类型：整数、浮点数、布尔值和字符。你可能在其他编程语言中见过它们。我们来深入了解它们在 Rust 中是如何工作的。

整数类型

整数（integer）是没有小数部分的数字。我们在第 2 章中使用过一种整数类型，即 u32 类型。这个类型声明表明，与它关联的值应该是一个占用 32 位空间的无符号整数（有符号整数类型以 i 而不是 u 开头）。表 3-1 展示了 Rust 内置的整数类型。我们可以使用其中任何一种变体来声明整数值的类型。

表 3-1：Rust 中的整数类型

长度有符号无符号
8 位i8u8
16 位i16u16
32 位i32u32
64 位i64u64
128 位i128u128
取决于架构isizeusize

每种变体都可以是有符号或无符号的，并且有明确的大小。有符号（signed）和无符号（unsigned）指的是数字能否为负数——换句话说，数字是否需要带有符号（有符号），还是说它永远只会是正数，因而可以不带符号表示（无符号）。这就像在纸上写数字：当符号很重要时，数字前会写上加号或减号；而当可以放心地假定数字为正数时，就不写符号。有符号数以二进制补码形式存储。

每种有符号变体可以存储从 −(2n − 1) 到 2n − 1 − 1（含两端）的数字，其中 n 是该变体使用的位数。因此，i8 可以存储从 −(27) 到 27 − 1 的数字，也就是 −128 到 127。无符号变体可以存储从 0 到 2n − 1 的数字，所以 u8 可以存储从 0 到 28 − 1 的数字，也就是 0 到 255。

另外，isize 和 usize 类型取决于运行程序的计算机的架构：在 64 位架构上是 64 位，在 32 位架构上是 32 位。

你可以使用表 3-2 中的任何一种形式来书写整数字面量。注意，可以属于多种数字类型的数字字面量允许使用类型后缀来指定类型，例如 57u8。数字字面量还可以使用 _ 作为视觉分隔符，让数字更易读，例如 1_000，它的值与写成 1000 完全相同。

表 3-2：Rust 中的整数字面量

数字字面量示例
十进制98_222
十六进制0xff
八进制0o77
二进制0b1111_0000
字节（仅限 u8）b'A'

那么，你该如何确定使用哪种整数类型呢？如果拿不准，Rust 的默认值通常是不错的起点：整数类型默认为 i32。使用 isize 或 usize 的主要场景是对某种集合进行索引。

整数溢出

假设你有一个 u8 类型的变量，它可以保存 0 到 255 之间的值。如果你试图把这个变量改为超出该范围的值，例如 256，就会发生整数溢出（integer overflow），这可能导致两种行为之一。在调试模式下编译时，Rust 会加入整数溢出检查，一旦发生溢出，程序就会在运行时 panic。Rust 用 panic 这个术语来表示程序因错误而退出；我们会在第 9 章“用 panic! 处理不可恢复错误”部分更深入地讨论 panic。

当你使用 --release 标志在发布模式下编译时，Rust 不会加入会导致 panic 的整数溢出检查。相反，如果发生溢出，Rust 会进行二进制补码回绕（two’s complement wrapping）。简单来说，大于该类型所能容纳的最大值的值会“回绕”到该类型所能容纳的最小值。以 u8 为例，值 256 会变成 0，值 257 会变成 1，以此类推。程序不会 panic，但变量的值可能并不是你所期望的。依赖整数溢出的回绕行为被认为是一种错误。

要显式地处理溢出的可能性，你可以使用标准库为原始数字类型提供的以下几类方法：

  • 在所有编译模式下都使用 wrapping_* 方法进行回绕，例如 wrapping_add。
  • 使用 checked_* 方法，在发生溢出时返回 None 值。
  • 使用 overflowing_* 方法，返回值以及一个表示是否发生溢出的布尔值。
  • 使用 saturating_* 方法，使结果饱和于该类型的最小值或最大值。

浮点类型

Rust 还有两种用于浮点数（floating-point number）的原始类型，浮点数就是带小数点的数字。Rust 的浮点类型是 f32 和 f64，大小分别为 32 位和 64 位。默认类型是 f64，因为在现代 CPU 上，它的速度与 f32 大致相同，但精度更高。所有的浮点类型都是有符号的。

下面是一个展示浮点数用法的例子：

文件名：src/main.rs

fn main() {
    let x = 2.0; // f64

    let y: f32 = 3.0; // f32
}

浮点数按照 IEEE-754 标准表示。

数值运算

Rust 的所有数字类型都支持你所期望的基本数学运算：加法、减法、乘法、除法和取余。整数除法会向零截断到最接近的整数。下面的代码展示了如何在 let 语句中使用每种数值运算：

文件名：src/main.rs

fn main() {
    // addition
    let sum = 5 + 10;

    // subtraction
    let difference = 95.5 - 4.3;

    // multiplication
    let product = 4 * 30;

    // division
    let quotient = 56.7 / 32.2;
    let truncated = -5 / 3; // Results in -1

    // remainder
    let remainder = 43 % 5;
}

这些语句中的每个表达式都使用了一个数学运算符，并求值为单个值，然后该值被绑定到一个变量上。附录 B 列出了 Rust 提供的所有运算符。

布尔类型

和大多数其他编程语言一样，Rust 中的布尔类型有两个可能的值：true 和 false。布尔值的大小为一个字节。Rust 中的布尔类型用 bool 表示。例如：

文件名：src/main.rs

fn main() {
    let t = true;

    let f: bool = false; // with explicit type annotation
}

布尔值主要用在条件判断中，例如 if 表达式。我们会在“控制流”部分介绍 if 表达式在 Rust 中是如何工作的。

字符类型

Rust 的 char 类型是语言中最原始的字母类型。下面是一些声明 char 值的例子：

文件名：src/main.rs

fn main() {
    let c = 'z';
    let z: char = 'ℤ'; // with explicit type annotation
    let heart_eyed_cat = '😻';
}

注意，char 字面量使用单引号指定，而字符串字面量则使用双引号。Rust 的 char 类型大小为 4 个字节，表示一个 Unicode 标量值（Unicode scalar value），这意味着它能表示的远不止 ASCII。带重音符号的字母，中文、日文和韩文字符，emoji，以及零宽空格，在 Rust 中都是有效的 char 值。Unicode 标量值的范围是 U+0000 到 U+D7FF 以及 U+E000 到 U+10FFFF（含两端）。不过，“字符”在 Unicode 中并不是一个真正的概念，所以你凭直觉认为的“字符”可能与 Rust 中的 char 并不一致。我们会在第 8 章“使用字符串存储 UTF-8 编码的文本”中详细讨论这个话题。

复合类型

复合类型（compound type）可以将多个值组合成一个类型。Rust 有两种原始的复合类型：元组和数组。

元组类型

元组（tuple）是一种将多个不同类型的值组合成一个复合类型的通用方式。元组的长度是固定的：一旦声明，它的大小就不能增大或缩小。

我们通过在圆括号内写一个以逗号分隔的值列表来创建元组。元组中的每个位置都有一个类型，而且元组中不同值的类型不必相同。在这个例子中，我们添加了可选的类型注解：

文件名：src/main.rs

fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);
}

变量 tup 绑定到整个元组，因为元组被视为一个单独的复合元素。要从元组中取出各个值，我们可以使用模式匹配来解构元组值，像这样：

文件名：src/main.rs

fn main() {
    let tup = (500, 6.4, 1);

    let (x, y, z) = tup;

    println!("The value of y is: {y}");
}

这个程序首先创建了一个元组并将其绑定到变量 tup 上。然后它通过 let 使用一个模式，将 tup 拆分成三个独立的变量 x、y 和 z。这个过程叫作解构（destructuring），因为它把单个元组拆成了三个部分。最后，程序打印出 y 的值，也就是 6.4。

我们也可以使用点号（.）后跟要访问的值的索引来直接访问元组元素。例如：

文件名：src/main.rs

fn main() {
    let x: (i32, f64, u8) = (500, 6.4, 1);

    let five_hundred = x.0;

    let six_point_four = x.1;

    let one = x.2;
}

这个程序创建了元组 x，然后使用各自的索引访问元组的每个元素。与大多数编程语言一样，元组的第一个索引是 0。

不包含任何值的元组有一个特殊的名字：单元（unit）。这个值及其对应的类型都写作 ()，表示一个空值或空的返回类型。如果表达式不返回任何其他值，就会隐式地返回单元值。

数组类型

另一种拥有多个值的集合的方式是数组（array）。与元组不同，数组中的每个元素都必须是相同的类型。与某些其他语言中的数组不同，Rust 中的数组长度是固定的。

我们把数组中的值写成方括号内以逗号分隔的列表：

文件名：src/main.rs

fn main() {
    let a = [1, 2, 3, 4, 5];
}

当你希望数据分配在栈上（与我们目前见过的其他类型一样），而不是分配在堆上时（我们会在第 4 章中进一步讨论栈和堆），或者当你想确保始终拥有固定数量的元素时，数组就很有用。不过，数组不如 vector 类型灵活。vector 是标准库提供的一种类似的集合类型，由于其内容存储在堆上，它的大小是允许增大或缩小的。如果你不确定该用数组还是 vector，那多半应该用 vector。第 8 章会更详细地讨论 vector。

然而，当你知道元素数量不需要改变时，数组会更有用。例如，如果你在程序中使用月份的名称，你很可能会使用数组而不是 vector，因为你知道它总是包含 12 个元素：

#![allow(unused)]
fn main() {
let months = ["January", "February", "March", "April", "May", "June", "July",
              "August", "September", "October", "November", "December"];
}

数组类型的写法是：在方括号中写上每个元素的类型、一个分号，然后是数组中元素的数量，像这样：

#![allow(unused)]
fn main() {
let a: [i32; 5] = [1, 2, 3, 4, 5];
}

这里，i32 是每个元素的类型。分号之后的数字 5 表示该数组包含五个元素。

你还可以通过在方括号中指定初始值、后跟一个分号、再跟上数组长度的方式，将数组初始化为每个元素都是相同的值，如下所示：

#![allow(unused)]
fn main() {
let a = [3; 5];
}

名为 a 的数组将包含 5 个元素，这些元素的初始值都是 3。这与写成 let a = [3, 3, 3, 3, 3]; 效果相同，只是更简洁。

访问数组元素

数组是一整块已知且大小固定的内存，可以分配在栈上。你可以使用索引来访问数组的元素，像这样：

文件名：src/main.rs

fn main() {
    let a = [1, 2, 3, 4, 5];

    let first = a[0];
    let second = a[1];
}

在这个例子中，名为 first 的变量会得到值 1，因为这是数组中索引 [0] 处的值。名为 second 的变量会从数组中索引 [1] 处得到值 2。

无效的数组元素访问

我们来看看如果尝试访问数组末尾之后的元素会发生什么。假设你运行下面这段代码（类似于第 2 章的猜数字游戏），从用户那里获取一个数组索引：

文件名：src/main.rs

use std::io;

fn main() {
    let a = [1, 2, 3, 4, 5];

    println!("Please enter an array index.");

    let mut index = String::new();

    io::stdin()
        .read_line(&mut index)
        .expect("Failed to read line");

    let index: usize = index
        .trim()
        .parse()
        .expect("Index entered was not a number");

    let element = a[index];

    println!("The value of the element at index {index} is: {element}");
}

这段代码能够成功编译。如果你使用 cargo run 运行这段代码并输入 0、1、2、3 或 4，程序会打印出数组中该索引处对应的值。如果你输入的是一个超出数组末尾的数字，例如 10，你会看到类似这样的输出：

thread 'main' panicked at src/main.rs:19:19:
index out of bounds: the len is 5 but the index is 10
note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace

程序在索引操作中使用无效值时产生了一个运行时错误。程序带着一条错误信息退出了，并没有执行最后的 println! 语句。当你尝试使用索引访问元素时，Rust 会检查你指定的索引是否小于数组长度。如果索引大于或等于长度，Rust 就会 panic。这种检查必须在运行时进行，尤其是在这种情况下，因为编译器不可能知道用户之后运行代码时会输入什么值。

这是 Rust 内存安全原则发挥作用的一个例子。在许多底层语言中，并不会进行这种检查，当你提供了错误的索引时，就可能访问到无效的内存。Rust 通过立即退出而不是允许这次内存访问并继续执行，来保护你免受此类错误的影响。第 9 章会进一步讨论 Rust 的错误处理，以及如何编写既不会 panic 也不会允许无效内存访问的可读、安全的代码。
