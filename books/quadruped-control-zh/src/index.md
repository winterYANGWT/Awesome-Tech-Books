# 前言

一台四足机器人站起来、走起来，背后是一整条链：关节电机把力矩命令变成转动，运动学把关节角换成足端位置，状态估计器从 IMU 和腿的读数里推算机身在哪里、跑多快，平衡控制器给支撑腿分配地面反力，步态规划决定哪条腿什么时候抬起、落在哪里，行走控制器把这些拼成一个 2 ms 一次的控制循环，再往上才是感知和导航。这本书沿着这条链从下往上讲，每一环都给出推导、代码和在仿真里实际跑出来的结果。

## 这本书和《四足机器人控制算法》

本书的章节结构参照《四足机器人控制算法——建模、控制与实践》（杭州宇树科技有限公司组编，卞泽坤、王兴兴编著，机械工业出版社，2023）编写，覆盖了该书全部 11 章的内容：每一节、每一个编号公式和每一个实践环节，在本书里都有对应的位置。每章最后一节“与原书的对应”列出原书各节在本书中的位置，[附录 A](appendix-mapping.md) 把全书的对应关系、原书编号公式和表格的位置汇总在一起。手里有原书的读者可以两本对照着读。

本书是原创的教程，不是原书的复制或摘编：正文是重新写的，插图由本书的示例脚本重新绘制或从仿真中渲染，示例代码也是重新写的。公式、电机通信协议这类客观内容与原书一致；原书的表格（例如电机报文格式）原样引用，并在表下注明出处。

和原书相比，有几处主要的不同：

- **实践平台**：原书的实践基于宇树的电机和整机、ROS1 + Gazebo 仿真和 unitree_guide 控制程序。本书的示例用 Python + MuJoCo 仿真同一款 A1 机器人，从电机接口到小跑和导航都能在一台没有机器人的电脑上跑起来；原书专门讲 C++ 的部分（面向对象、Eigen 矩阵运算、实时进程）仍然用 C++ 示例。
- **ROS**：ROS1 已于 2025 年停止维护，本书讲到 ROS 和导航功能包时用 ROS 2 的概念和命令，并说明与原书 ROS1 写法的对应。
- **实测带来的修正**：每个结论都在仿真里验证过，和原书说法不一致的地方，正文以实测为准并写明原因。例如：小跑步态的支撑占空比在仿真里取 0.6 而不是 0.5（0.5 时双腿支撑会激起横滚振荡）；Eigen 的固定尺寸矩阵默认不会清零；用摩擦系数 μ 构造的摩擦四棱锥是摩擦锥的外近似而不是保守近似；平衡控制器使用整机折算到机身的等效惯量。

## 示例和环境

所有示例都放在 `code/` 目录下，各章的示例在 `code/chNN/`，全书共用的控制代码包在 `code/quadruped/`。这个包按控制框架划分模块：电机接口与混合控制律、仿真封装、旋转与运动学、有限状态机、状态估计器、平衡控制器、步态与摆动腿轨迹、行走控制器、导航，每章用到其中一部分，最后合成一个能站立、调姿、小跑、绕障导航的完整控制器。控制器只使用 IMU、关节编码器和足端接触这些真实机器人上也有的传感器读数，不读取仿真里的真值；包的测试里专门有一项检查这一点。

示例在下面的环境中实际运行过，正文引用的数值输出和图都由示例脚本生成：

- Python 3.12、MuJoCo 3.17、NumPy、SciPy、Matplotlib、OSQP；C++ 示例用 Clang 21 和 Eigen 3.4 编译。
- 机器人模型是 MuJoCo Menagerie 中的 Unitree A1（BSD-3-Clause，版权归 Unitree Robotics）。模型不随本书分发，运行 `code/fetch_a1.sh` 下载本书验证时使用的版本。
- 运行单个示例：进入 `code/chNN/` 目录，执行 `PYTHONPATH=.. python3 N_k_name.py`，图存到该目录的 `figs/` 下；没有显示器的机器上设置 `MUJOCO_GL=egl`。

依赖真实硬件的内容（电机接线与配置、真机网络、在机器人上编译、实机导航）按原书和宇树公开的资料讲清步骤，标为 **【需要实机】**；依赖 ROS 2 但本书没有运行的命令标为 **【需要 ROS 2 环境】**。这两类内容都没有在本地验证。

## 怎么读

读者需要有线性代数、理论力学和编程（Python，部分章节用到 C++）的基础。各章按依赖关系排列：第 1–3 章是机器人、电机和控制框架，第 4–6 章是刚体运动学、单腿和整机的运动学与动力学，第 7–10 章依次是状态估计器、平衡控制器、步态与轨迹规划、行走控制器，第 11 章是感知与导航。后面的章节会用到前面推导的公式和代码，建议按顺序读；只关心某个控制环节的读者，可以先读第 4–6 章，再直接跳到对应的章节。
