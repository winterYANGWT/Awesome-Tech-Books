# 译者前言

这是 Swift 官方教程 *The Swift Programming Language*（Swift 6.4）的简体中文译本。全书分四部分：
“欢迎使用 Swift”是语言概览和一次快速上手；“语言指南”从常量、变量讲到并发、宏和内存安全，是主体；
“语言参考”给出词法、类型、表达式、语句、声明等的形式定义和完整语法；最后是修订历史。

## 版本与来源

## 翻译说明

- 代码、关键字、类型名和编译器信息保持英文，代码里的注释和输出也不翻译，方便和英文资料对照。
- 术语尽量沿用中文 Swift 社区的通行译法，例如 property 译作“属性”，attribute（`@` 开头的）译作“特性”，
  initializer 译作“构造器”。
- 章节和小节的链接锚点与英文版相同，英文版的链接把域名和路径换一下就能对到本书的同一节。
- 语言参考中的形式语法保持英文原样。
- 本译本在 AI 辅助下完成翻译和校对，欢迎指正错误。
