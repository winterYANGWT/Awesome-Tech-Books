# 运营指标口径

## 订单数

当月创建、且状态不是“已取消”的订单数。分母用这个数。

## 实付总额

同一批订单的 `total` 之和，单位元，保留两位小数。

## 退货订单数

当月创建的订单中，在 `returns` 表里有至少一条退货记录的订单数。
按订单去重：一张订单有两条部分退款记录，只算一个退货订单。
部分退款也算退货。

## 退货率

退货订单数 ÷ 订单数，保留一位小数。
不要用退货记录数做分子，也不要把已取消订单算进分母。

## 前三个退货原因

按退货记录的 `reason` 计数，从高到低取前三；并列时按原因名称排序。

## 快递破损数

当月创建订单的 `shipments.damaged = 1` 的记录数，排除已取消订单。
这是物流记录的破损数，不等于退货订单数。
