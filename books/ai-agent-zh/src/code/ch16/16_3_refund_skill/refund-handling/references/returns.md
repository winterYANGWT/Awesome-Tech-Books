# 退货和退款（2026-07-01 起）

## 退货期限

- 签收后 15 天内可以申请退货，以物流记录的签收日期为准。
- 教辅、考试用书拆封后不退，除非有质量问题。
- 电子书、已使用的礼品卡不退。

## 质量问题

- 缺页、错装、印刷模糊、装订脱落、运输中破损，都算质量问题。
- 质量问题退全款（书款加运费），不受 15 天限制，签收后 60 天内都可以申请。
- 金额 100 元以下的质量问题不用要求顾客寄回。

## 非质量问题

- 不想要了、买错了：只退书款（按实付折算），原订单的运费不退。
- 部分退货：只退所退那几本的书款。

## 退款金额和权限

- 退款原路返回，1–3 个工作日到账。
- 一张订单累计退款不能超过实付金额。
- 单笔退款超过 500 元，需要主管批准，客服不能直接操作。
- 已经全额退款的订单不能再退。
