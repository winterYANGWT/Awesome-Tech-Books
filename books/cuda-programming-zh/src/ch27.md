# 第 27 章 CPU 基线与热点

前面各章用的都是为了说明某一点而设计的小程序。第六部分换一种方式：拿一个完整的科学计算程序，从 CPU 版本出发，一步步搬到 GPU 上，看看前面讲过的东西在真实的程序里怎样组合起来，又会遇到哪些单独讲某个特性时遇不到的问题。

例子是分子动力学（molecular dynamics，MD）：给定一群粒子和它们之间的相互作用，按牛顿运动定律一步步推进它们的位置和速度。这是 GPU 上最成功的应用之一，也很能说明问题：既有大量的并行计算，又有不规则的数据访问。这一章先写好 CPU 版本、找出热点；第 28 章只把最热的部分搬到 GPU；第 29 章把整个时间步都留在 GPU 上。

本部分的示例选题参考了樊哲勇《CUDA 编程：基础与实践》（清华大学出版社，2020）。该书基于 CUDA 10.x 编写，部分工具和性能结论已经过时，这里只沿用示例思路。

## 27.1 模型

粒子之间用 Lennard-Jones 势相互作用，这是模拟惰性气体最经典的模型。两个距离为 r 的粒子之间的势能是 4(r⁻¹² − r⁻⁶)，近了互相排斥，稍远一点互相吸引，再远就几乎没有作用了。所以只计算距离小于截断半径 r_c = 2.5 的粒子对，并把势能整体平移一点，让它在截断处正好为 0，这样粒子对跨过截断半径时能量不会跳变。程序使用约化单位，粒子质量和势能参数都取 1。

粒子放在一个周期性的立方盒子里：从一边出去的粒子从对面进来，计算两个粒子的距离时取所有周期镜像里最近的那个（最小镜像）。初始时粒子排成面心立方（FCC）晶格，速度取随机值，缩放到指定的温度。时间推进用速度 Verlet 算法：先用当前的力把速度推进半步，用速度把位置推进一整步，在新位置上重新算力，再把速度推进另外半步。

## 27.2 邻居表

每个粒子只和截断半径以内的粒子有作用，但要知道哪些粒子在截断半径以内，最笨的办法是检查所有粒子对，计算量是 N² 级的，5 万多个粒子就有 15 亿对。标准的做法是邻居表：给每个粒子记下它附近的粒子，算力时只看这些。

建邻居表本身也不能检查所有粒子对。程序用格子法：把盒子切成边长不小于邻居半径的小格子，先把每个粒子放进它所在的格子，然后每个粒子只需要检查自己和周围 26 个格子里的粒子：

```cpp
{{#include code/ch27/md_common.h:neighbors}}
```

邻居表的半径比截断半径多 0.3（叫 skin），这样粒子移动一点点以后，邻居表依然完整，不必每一步都重建。程序每 10 步重建一次。`half` 为真时，每对粒子只在编号小的那个粒子的表里记一次。

```text
  步数     动能/N     势能/N     总能量/N
     0    1.08300   -6.33281   -5.249812

总能量相对漂移 1.7e-05，邻居表里最多 77 个邻居（上限 128）

阶段        时间        占比    每步
求力      11955.1 ms   67.1%   23.91 ms
邻居表     5711.7 ms   32.0%   11.42 ms
积分        159.5 ms    0.9%    0.32 ms
合计      17826.2 ms           35.65 ms
```

先看能量。晶格一开始的势能很低，粒子获得速度以后很快离开晶格位置，一部分动能转化成势能，动能从 1.08 降到 0.59 左右。但总能量始终守恒在 −5.2497 附近，500 步的相对漂移只有 1.7 × 10⁻⁵，这说明积分、求力、邻居表都是对的。后面每改一步，都先用这组能量数字检查结果有没有变。

再看时间：每步 35.65 ms，求力占三分之二，建邻居表占三分之一（虽然每 10 步才建一次，但每次要 110 多毫秒），积分几乎可以忽略。

## 27.5 搬到 GPU 之前

热点很清楚，最自然的第一步是把求力搬到 GPU 上：它占了 67% 的时间，而且每个粒子的计算互相独立，正适合 GPU。但先算一笔账：根据 Amdahl 定律，如果只加速占 67% 的那部分，即使它快到不花时间，整个程序最多也只能快 1 / (1 − 0.67) ≈ 3 倍。剩下的 32% 不处理，就是天花板。

还有第 1 章的教训：每一步算力之前要把位置拷上去，算完把力拷回来。数据量不大（5 万多个粒子，每步上下合计约 3 MB），但每步都要来一回。下一章就按这个最直接的思路先做一版，看看实际情况。

## 27.6 回头看

CPU 版本的 MD 程序由三部分组成：用格子法每 10 步建一次邻居表，利用牛顿第三定律只算一半粒子对的求力，以及速度 Verlet 积分。55296 个粒子每步 35.65 ms，求力占三分之二，建邻居表占三分之一。总能量的漂移是检验后续每个 GPU 版本的标准。按 Amdahl 定律，只移植求力最多快 3 倍。
