# 前言

这是一本中文的 CUDA 入门和进阶教程。它的写法和常见的教程不太一样：几乎每一节都围绕一个能直接编译运行的程序展开，先运行，看输出，再解释输出里的数字为什么是这样。书里引用的每一个时间、带宽、误差，都是在同一台机器上实际跑出来的，程序和完整的输出都可以找到。

这样写，是因为 GPU 编程里很多道理只有看到数字才有体会。“合并访问很重要”这句话谁都会说，看到只是把粒子数据从结构体的数组换成几个独立的数组，同一个统计 kernel 就快了 6 倍多（第 8 章），才知道它有多重要；“数据要留在 GPU 上”也是一样，第 29 章的分子动力学程序只移植求力时快了 1.6 倍，把整个时间步都留在 GPU 上以后快了 84 倍。也有一些流传很广的说法，在今天的 GPU 和 CUDA 版本上已经不成立了，实测一下就能看出来，书里遇到这种情况会直接说明。

## 适合谁读

读者需要会写 C 或 C++，知道指针、数组、模板是怎么回事。不需要任何 GPU 编程经验，也不需要了解图形学。第一部分从一个普通的 for 循环讲起，到第 5 章就能写出结构正确、出错时知道怎么排查的 CUDA 程序。后面的章节逐步深入到性能分析、异步执行、新一代 GPU 的协作机制和系统层面的话题，已经写过一些 CUDA 代码的读者，可以直接跳到感兴趣的部分。

## 怎么读

第一部分是后面所有内容的基础，建议按顺序读完。第二、三部分分别解决“kernel 本身怎么写快”和“怎么让 CPU、数据拷贝和 GPU 计算同时进行”，两部分互相独立，可以按需要先读其中一部分，但都值得读。第四部分的功能大多要求较新的 GPU（Ampere、Hopper 或更新的架构），适合已经熟悉前面内容、需要榨取性能的读者。第五部分的库随时都可以穿插阅读。第六部分是一个完整的案例，把前面各部分的内容串起来，适合在读完前三部分以后阅读。第七部分各章相对独立，遇到相关的需求时再读也可以。

每章末尾有“回头看”和练习。练习大多是在本章程序的基础上改一改、再测一测，动手做一遍，比读十遍更有用。

## 测量平台

书中所有的程序都在同一台笔记本电脑上编译运行：

- GPU：NVIDIA GeForce RTX 5060 Laptop GPU（Blackwell 架构，计算能力 12.0），26 个 SM，8 GB GDDR7 显存，128 位总线，实测显存带宽约 336 GB/s，PCIe 4.0 x8；
- CPU：AMD Ryzen 9 9955HX，16 核 32 线程，系统内存约 14 GB；
- 软件：Linux（内核 7.0），NVIDIA 驱动 610.57.04，CUDA 13.3，GCC 15.2。

这是一块消费级的笔记本显卡，和数据中心的 GPU 相比，SM 少、显存带宽低、双精度运算很慢，有些功能（比如多 GPU 之间的直连、multicast）根本无法测试。你在自己的机器上运行这些程序，得到的数字一定会不同，重要的是数字之间的关系：哪个版本更快、快多少倍、瓶颈在哪里、改变一个参数以后趋势怎样。书中凡是只在这台机器上观察到、不一定能推广的现象，都会说明。遇到书里没法实测的内容，也会明确说出来。

## 代码在哪里

每章的示例程序放在本书源码仓库的 `src/code/chNN/` 目录下（正文里的文件名可以直接点开），每个程序开头的注释写明了用途和编译命令，大多数程序用一条 `nvcc` 命令就能编译。正文里贴出的程序输出都是原样复制的，完整的输出存档在仓库的 `runs/chNN/` 目录。书中的代码按 CUDA 13 的 API 编写，大部分也能在 CUDA 12 上编译；用到较新的功能时，正文会说明对 CUDA 版本和 GPU 架构的要求。

所有程序都用同一个 `CHECK` 宏检查 CUDA 调用的返回值，出错时打印文件名、行号、错误名称和说明，第 2 章介绍了它。kernel、warp、stream、block、shared memory 等术语保留英文，第一次出现时会解释。
