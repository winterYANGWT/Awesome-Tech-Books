# 前言

C++ 的经典规则书大多写于 1996 到 2005 年之间。它们讲的道理今天大部分仍然成立，但读起来有三个麻烦。第一，规则是一条一条的：同一个问题，比如“对象怎么安全地拷贝”，散落在四五本书的十几个条目里，读完一本还得自己去把另一本的相关条目找出来对照。第二，几本书大量重叠，偶尔还互相矛盾。第三，C++11 到 C++23 改掉了不少前提：有的规则被新特性取代了，有的规则还对但理由变了，还有的规则在新标准下更加重要。

这本书把八本规则书的 410 条规则按主题重新组织成 36 章。每一节围绕一个问题，把相关的两到五条规则串成一条线来讲：它们针对同一个问题的哪一面，彼此怎样呼应或分歧，新标准改变了什么，今天该怎么写，哪些编译器警告和工具能替你把关。基准是 C++20，C++23 和 C++26 的内容会注明版本和编译器支持情况。

## 怎么读

各章可以按顺序读，也可以按问题跳着读：前五章是类型、初始化和类型推导这些每天都在用的基础，第二、三部分是资源管理和异常，后面依次是类与继承、模板、标准库、性能与并发、代码组织与工程。想知道某一条原书规则在本书哪里讲，查[附录 A](appendix-index.md)。

每章末尾有一张“原书条目对照”表，列出本章覆盖的条目和它在新标准下的状态，状态只有四种：

- **仍成立**：规则和理由都没变。
- **更加重要**：新标准或今天的工程实践让它更值得遵守。
- **部分过时**：结论还对，但理由、写法或适用范围变了。
- **已过时**：被新特性取代，或者结论被推翻。

## 示例是怎么验证的

正文里的完整程序都放在 `src/code/` 下，每一个都实际编译、运行过：

- 编译器是 Clang 21.1.8，标准库是 libstdc++ 15（GCC 15.2 自带）；少数用到 `<mdspan>` 或 `import std` 的示例用 libc++ 21。
  编译选项是 `-std=c++20 -Wall -Wextra -Wpedantic -Werror`，用到 C++23 特性的示例会注明 `-std=c++23`。
- 能运行的示例都在 AddressSanitizer 和 UndefinedBehaviorSanitizer 下运行，必须干净退出。
- 反例也是真实的：编译不过的写法，书里贴的是 clang 的报错；会触发警告的写法，贴的是警告原文；
  运行时出事的写法（悬垂引用、越界、重复释放、数据竞争），贴的是 sanitizer 当场给出的报告。
- 所有示例另用 GCC 15.2 核对一遍；两个编译器结论不同的地方，正文会写明。
- 正文引用的输出都由检查脚本运行程序后生成，没有手写或改动。计时类的数字来自一台 AMD Ryzen 9 9955HX，
  只说明数量级和趋势。

C++26 还没有完全落地，Clang 21 也还不支持其中的 contracts、静态反射等特性。涉及这些内容的代码片段没有编译验证，正文会明确标出。
